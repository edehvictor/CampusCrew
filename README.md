# Campuscrew

Book local services on your own or with neighbours.

This is the Book One demo. Start with the sample cleaning request. Accept the quote, simulate funding, submit a completion note, and approve the simulated payout. You can also post requests, send a quote for a sample request, and filter by category and service area.

```sh
npm install
npm run dev
```

The browser stores demo state locally. All G$ amounts, funding, payouts, and refunds are simulations. The demo has no external account or shared database.

Based on the Chucks1093 Next.js server template. The example to-do API is excluded from this static demo.
